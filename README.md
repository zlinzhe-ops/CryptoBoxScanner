# 虚拟货币箱体震荡选币软件

每日自动扫描 Gate.io 上所有 USDT 交易对，识别处于**箱体震荡**（横盘整理）形态的币种，并列出支撑位、阻力位和价格区间。

> **数据源**：默认使用 **Gate.io**（api.gateio.ws），国内无需代理可直接访问。
> 也支持 Binance、CoinGecko（需代理）。

---

## 🖥️ 图形界面版本（推荐）

**方式一：直接运行（需要 Python）**

```bash

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# 2. 启动 GUI
python main.py
```


## ⌨️ 命令行版本

### 环境要求
- Python 3.8+
- `pip install requests`

### 运行

```bash
# 全量扫描（Gate.io，国内可直接访问，约 2-5 分钟）
python crypto_box_scanner.py

# 指定其他数据源
python crypto_box_scanner.py --source binance     # 需要代理
python crypto_box_scanner.py --source coingecko   # 需要代理

# 测试模式（仅扫描 20 个主流币种，约 10 秒）
python crypto_box_scanner.py --test
python crypto_box_scanner.py --test --source gateio

# 查看帮助
python crypto_box_scanner.py --help
```

### 字段解释

| 字段 | 说明 |
|------|------|
| Symbol | 交易对名称 |
| 支撑位 | 箱体下边界价格（买入参考区） |
| 阻力位 | 箱体上边界价格（卖出参考区） |
| 振幅 | 箱体宽度百分比 = (阻力-支撑)/支撑 |
| 当前价 | 最新收盘价 |
| 位置 | 当前价在箱体内的位置（0%=支撑位, 100%=阻力位） |
| 置信度 | 综合评分 0-100，★ 标记 ≥80 分的高质量箱体 |

### JSON 输出文件

每次扫描在 `output/` 目录生成两个文件：
- `box_scan_YYYYMMDD_HHMMSS.json` — 带时间戳的完整结果
- `box_scan_latest.json` — 最新结果的副本

## 箱体检测算法

对每个币种取最近 **30 根日线 K 线**，通过以下 **6 步** 判定：

1. **支撑/阻力计算**：取最高 5 根 K 线的最高价均值 = 阻力位，最低 5 根的最低价均值 = 支撑位
2. **振幅范围**：箱体振幅必须在 **3% ~ 25%** 之间
3. **触及验证**：支撑和阻力各自至少被 **触及 2 次**（2% 容差）
4. **趋势平坦**：收盘价线性回归斜率归一化后 **< 0.15**，确保横盘而非上升/下降通道
5. **包含率**：至少 **70%** 的收盘价落在箱体区间内
6. **当前位置**：最新收盘价必须在箱体之内

## 置信度评分（0-100分）

| 维度 | 权重 | 说明 |
|------|------|------|
| 触及质量 | 30分 | 支撑和阻力各15分，触及次数越多越好 |
| 包含率 | 25分 | 价格在箱体内的比例越高越好 |
| 趋势平坦度 | 20分 | 价格越横盘越好 |
| 箱体宽度 | 15分 | 5%-15% 为最佳交易区间 |
| 位置优势 | 10分 | 越接近支撑位（买入区）得分越高 |

## 每日自动运行

使用 Windows 任务计划程序：

1. 打开"任务计划程序"
2. 创建基本任务 → 触发器：每天 08:00
3. 操作：启动程序
   - 程序：`python.exe`
   - 参数：`f:\api监控软件\虚拟货币选币软件\crypto_box_scanner.py`
   - 起始于：`f:\api监控软件\虚拟货币选币软件`

## 可调参数

编辑 `crypto_box_scanner.py` 顶部的常量即可调整检测策略：

```python
KLINE_LIMIT = 30            # K线数量（建议 20-60）
MIN_RANGE_PCT = 3.0         # 最小振幅%（低于此值视为稳定币行为）
MAX_RANGE_PCT = 25.0        # 最大振幅%（高于此值视为趋势行情）
MIN_TOUCHES = 2             # 触及次数要求
MIN_VOLUME_USDT = 1_000_000 # 最小24h成交量（USDT）
```
